# Core Stack

AI reasons
→ n8n orchestrates
→ Supabase validates
→ GitHub protects
→ Notion visualizes
→ Lovable surfaces

---

## Core/Sleeve Doctrine

Core:
- deterministic
- auditable
- industry agnostic
- governance controlled

Sleeves:
- industry overlays
- isolated extensions
- must never corrupt Core

---

## Canonical Core Ownership

Supabase owns:
- validation
- scoring
- auditability
- transactional logic
- longitudinal intelligence

GitHub owns:
- rollback
- migration memory
- operational history
- governance tracking

n8n owns:
- orchestration workflows
- scheduled checks
- controlled cross-system handoffs
- snapshot/checkpoint triggers
- non-canonical automation logs

---

## Prohibited Architecture

- hidden logic in Lovable
- pseudo-Core in n8n
- Notion as canonical truth
- undocumented mutations
- unrestricted AI writes to Supabase Core
