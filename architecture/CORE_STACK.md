# Core Stack

AI reasons
→ Make orchestrates
→ Supabase validates
→ GitHub protects
→ Notion visualizes
→ Lovable surfaces

---

## Core/Sleeve Doctrine

Core:
- deterministic
- auditable
- industry agnostic
- governance controlled

Sleeves:
- industry overlays
- isolated extensions
- must never corrupt Core

---

## Canonical Core Ownership

Supabase owns:
- validation
- scoring
- auditability
- transactional logic
- longitudinal intelligence

GitHub owns:
- rollback
- migration memory
- operational history
- governance tracking

---

## Prohibited Architecture

- hidden logic in Lovable
- pseudo-Core in Make
- Notion as canonical truth
- undocumented mutations
